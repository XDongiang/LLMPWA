## Required architecture for run/fit_script.py

Event-level data parallel + Newton-CG with a **chief-only optimizer**:

- each process/GPU holds an event shard
- likelihood / grad / HVP reduce across devices via XLA all-reduce on sharded arrays
- **only process 0 (chief)** runs `scipy.optimize.minimize(Newton-CG)`
- every other process (worker) does NOT run SciPy. Instead it loops in
  `serve_optimizer_requests()`: each iteration `broadcast_one_to_all`s a request
  tuple (op, x, vector); op is one of OP_OBJECTIVE / OP_GRADIENT / OP_HESSIAN_PRODUCT /
  OP_STOP; the worker executes exactly the same JAX call the chief is about to run.
- **Rationale (required)**: Newton-CG's internal CG sub-iteration count varies, so if
  every process ran its own minimize the collective order would diverge on the first
  CG restart → NCCL deadlock. The request/response loop guarantees both sides issue
  identical, one-to-one collectives: chief always `broadcast`s its request **before**
  evaluating objective/grad/HVP, so the worker's matching `broadcast` + JAX call is
  deterministically synchronized.
- only process 0 writes logs/results

### 1) init_distributed()
```python
def init_distributed():
    coordinator = os.environ.get("JAX_COORDINATOR_ADDRESS", "")
    num_processes = int(os.environ.get("JAX_NUM_PROCESSES", 1))
    process_id = int(os.environ.get("JAX_PROCESS_ID", 0))
    if num_processes > 1:
        jax.distributed.initialize(
            coordinator_address=coordinator,
            num_processes=num_processes,
            process_id=process_id,
        )
    return num_processes, process_id
```

### 2) build_mesh()
```python
def build_mesh():
    return Mesh(jax.devices(), axis_names=("event",))
```

### 3) main() outline
1. `num_processes, process_id = init_distributed()`; `is_chief = (process_id == 0)`
2. `config.update("jax_enable_x64", True)`
3. `logger = setup_logging()`; only chief logs status / process counts
4. `data = load_data(); data = normalize_data(data)`
5. `data_size = len(data["data_phi_kk"])` (or the real-data 1D event key present)
6. `mesh = build_mesh()`
7. Inside mesh context (`with jax.set_mesh(mesh):` or equivalent for this JAX version):
   - `jax_data = shard_data_distributed(data, mesh)`
   - Build callable NLL over `(args, jax_data)` from likelihood_function
   - **Do not** close over non-addressable sharded arrays inside jit if multi-process
     forbids it; pass `jax_data` as an explicit argument.
   - Grad: `grad(nll, argnums=0)` (differentiate only args)
   - HVP: prefer jvp-of-grad with zero data tangent, e.g.
     `zero_data = jax.tree.map(np.zeros_like, jax_data)` then
     `jvp(grad_fn, (x, jax_data), (v, zero_data))[1]`
     (or use `hvp_combined_likelihood` if it already matches this contract)
   - `args_list, _, _ = make_initial_args()`
   - replicate args: `param_sharding = NamedSharding(mesh, P())`;
     `put_param = lambda v: device_put(np.asarray(v), param_sharding)`
   - `jit_likelihood = jit(nll)`, `jit_grad = jit(grad(...))`, `jit_hvp = jit(hvp...)`
   - smoke: one likelihood eval + one HVP on all processes; chief logs scalars/shapes;
     then barrier `multihost_utils.sync_global_devices("fit-smoke-complete")` when
     `num_processes > 1`
   - **OP codes**: `OP_STOP=0, OP_OBJECTIVE=1, OP_GRADIENT=2, OP_HESSIAN_PRODUCT=3`
   - **`broadcast_optimizer_request(op, x, vector)`** wraps
     `multihost_utils.broadcast_one_to_all({"op": onp.asarray(op, onp.int32),
     "x": onp.asarray(x, onp.float64), "vector": onp.asarray(vector, onp.float64)})`
   - **worker branch**:
     ```python
     if num_processes > 1 and not is_chief:
         serve_optimizer_requests()
         return 0
     ```
   - `serve_optimizer_requests()` loop (worker side, mirrored one-to-one):
     ```python
     def serve_optimizer_requests():
         while True:
             packet = broadcast_optimizer_request(OP_STOP, zero_vector, zero_vector)
             op = int(onp.asarray(packet["op"]))
             if op == OP_STOP:
                 break
             x = onp.asarray(packet["x"])
             vector = onp.asarray(packet["vector"])
             if op == OP_OBJECTIVE:
                 raw_objective(x)
             elif op == OP_GRADIENT:
                 raw_objective_grad(x)
             elif op == OP_HESSIAN_PRODUCT:
                 raw_objective_hvp(x, vector)
             else:
                 raise ValueError("Unknown optimizer request op: {}".format(op))
     ```
   - chief-side raw ops and dispatch:
     ```python
     def raw_objective(x):   return float(jit_likelihood(put_param(x), jax_data))
     def raw_objective_grad(x): return onp.asarray(jit_grad(put_param(x), jax_data))
     def raw_objective_hvp(x, vector):
         return onp.asarray(jit_hvp(put_param(x), put_param(vector), jax_data))

     def dispatch(op, x, vector=None):
         if num_processes > 1:
             broadcast_optimizer_request(op, x, zero_vector if vector is None else vector)

     def objective(x):     dispatch(OP_OBJECTIVE, x); return raw_objective(x)
     def objective_grad(x): dispatch(OP_GRADIENT, x); return raw_objective_grad(x)
     def objective_hvp(x, vector):
         dispatch(OP_HESSIAN_PRODUCT, x, vector); return raw_objective_hvp(x, vector)
     ```
   - SciPy (chief only, after the worker branch above has returned on workers):
     ```python
     result = minimize(
         fun=objective,
         x0=onp.asarray(args_list),
         jac=objective_grad,
         hessp=objective_hvp,
         method="Newton-CG",
         callback=my_callback,
         options={"disp": False, "xtol": 1.0e-8},   # + "maxiter": N when KKDIS_MAXITER>0
     )
     # finally:
     #   if num_processes > 1:
     #       broadcast_optimizer_request(OP_STOP, zero_vector, zero_vector)
     ```
   - callback: (chief) counts iterations, evaluates objective (this keeps the worker
     in lock-step) and logs `likelihood=... elapsed=...`; workers stay in the
     request loop, no logging
   - After optimize: build Hessian columns via `objective_hvp` on the basis vectors;
     `hessian = 0.5*(H+H.T)`; `ferror = sqrt(diag(inv(hessian)))`
   - **Only chief** writes (respect `KKDIS_OUTDIR` env → `output/<dir>/` when set):
     - `output/fit/fit_result_values.npy`
     - `output/fit/fit_result_errors.npy`
     - `save_result(result.x, ferror, "output/fit/free_params_fitted.toml")`
     - log `Fit finished: success=... status=... likelihood=... iterations=...`
   - Optional env overrides for multi-start comparison:
     `KKDIS_X0_NPY` (custom initial args), `KKDIS_OUTDIR`, `KKDIS_MAXITER`
8. `return 0`
9. `if __name__ == "__main__": raise SystemExit(main())`
