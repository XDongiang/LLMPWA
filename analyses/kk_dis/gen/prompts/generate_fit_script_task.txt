## Required architecture for run/fit_script.py

Event-level data parallel + Newton-CG:
- each process/GPU holds an event shard
- likelihood / grad / HVP reduce across devices via XLA all-reduce on sharded arrays
- SciPy Newton-CG outer loop runs on every process with the same inputs and collective order
- only process 0 writes logs/results

### 1) init_distributed()
```python
def init_distributed():
    coordinator = os.environ.get("JAX_COORDINATOR_ADDRESS", "")
    num_processes = int(os.environ.get("JAX_NUM_PROCESSES", 1))
    process_id = int(os.environ.get("JAX_PROCESS_ID", 0))
    if num_processes > 1:
        jax.distributed.initialize(
            coordinator_address=coordinator,
            num_processes=num_processes,
            process_id=process_id,
        )
    return num_processes, process_id
```

### 2) build_mesh()
```python
def build_mesh():
    return Mesh(jax.devices(), axis_names=("event",))
```

### 3) main() outline
1. `num_processes, process_id = init_distributed()`; `is_chief = (process_id == 0)`
2. `config.update("jax_enable_x64", True)`
3. `logger = setup_logging()`; only chief logs status / process counts
4. `data = load_data(); data = normalize_data(data)`
5. `data_size = len(data["data_phi_kk"])` (or the real-data 1D event key present)
6. `mesh = build_mesh()`
7. Inside mesh context (`with jax.set_mesh(mesh):` or equivalent for this JAX version):
   - `jax_data = shard_data_distributed(data, mesh)`
   - Build callable NLL over `(args, jax_data)` from likelihood_function
   - **Do not** close over non-addressable sharded arrays inside jit if multi-process
     forbids it; pass `jax_data` as an explicit argument.
   - Grad: `grad(nll, argnums=0)` (differentiate only args)
   - HVP: prefer jvp-of-grad with zero data tangent, e.g.
     `zero_data = jax.tree.map(np.zeros_like, jax_data)` then
     `jvp(grad_fn, (x, jax_data), (v, zero_data))[1]`
     (or use `hvp_combined_likelihood` if it already matches this contract)
   - `args_list, _, _ = make_initial_args()`
   - replicate args: `device_put(np.asarray(args_list), NamedSharding(mesh, P()))`
   - `jit_likelihood = jit(nll)`, `jit_grad = jit(grad(...))`, `jit_hvp = jit(hvp...)`
   - smoke: one likelihood eval + one HVP; chief logs scalars/shapes
   - SciPy:
     ```python
     result = minimize(
         fun=lambda x: float(jit_likelihood(np.asarray(x), jax_data)),
         x0=onp.asarray(args_list),
         jac=lambda x: onp.array(jit_grad(np.asarray(x), jax_data)),
         hessp=lambda x, p: onp.array(jit_hvp(np.asarray(x), np.asarray(p), jax_data)),
         method="Newton-CG",
         callback=my_callback,
         options={"disp": False, "xtol": 1e-8},
     )
     ```
   - **All processes** run the same minimize loop (identical collective order)
   - callback: every process evaluates likelihood (sync); only chief logs
   - After optimize: build Hessian columns via HVP on all processes;
     `ferror = sqrt(diag(inv(H)))`
   - **Only chief** writes:
     - `output/fit/fit_result_values.npy`
     - `output/fit/fit_result_errors.npy`
     - `save_result(result.x, ferror, "output/fit/free_params_fitted.toml")`
8. `return 0`
9. `if __name__ == "__main__": raise SystemExit(main())`
