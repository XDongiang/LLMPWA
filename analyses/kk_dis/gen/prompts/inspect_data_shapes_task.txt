## Goal
Build the data-preprocessing stage for this distributed fit:
1. Inspect npy shapes for all needed variables.
2. Generate three function fragments used by the fit script:
   - load_data()
   - normalize_data(data)
   - shard_data_distributed(data, mesh)

Reference semantics (adapt names/paths to THIS analysis; do not invent vars):
- load_data: load real_data + mc_truth npy for each sbc/amp var; tile with n_repeat;
  create truth_* by slicing mc_* along the event axis to the **first
  n_truth_mc * n_repeat** events. Default **n_truth_mc = 150000** — this is an
  intentional cap on truth-MC compute/memory (not equal to real-data n_data).
  If mc event count < n_truth_mc * n_repeat, slice to available length (or clamp).
- normalize_data: for multi-component amplitude arrays (phif*-style), compute
  regular factors from mc arrays and einsum-scale data/mc/truth.
- shard_data_distributed: convert to jnp arrays and device_put with NamedSharding:
  1D event arrays → P("event"); 3D (channels, events, components) → P(None, "event", None).

## Required procedure
1. Extract unique sbc / amp names from stripped_config / lists above.
2. shell/list data/ candidates; use numpy (mmap) to print shape+dtype for each needed npy.
   Record real_data event counts (n_data) for the report / later data_size usage, and
   mc_truth event counts. All real_data event lengths for the same analysis should agree;
   if not, report the inconsistency.
3. Write the shape report **once** with the write tool to:
   gen/fragments/data_shapes_report.txt
   Contents: unique vars; table path/shape/dtype/MISSING; n_data; mc sizes;
   chosen n_truth_mc (default 150000); short summary.
   This file is the authoritative stage output field `all`. Do **not** rely on
   task.finish(result=...) to carry the report body.
4. Generate three Python fragments (no markdown fences, no #=== section banners):

   a) gen/fragments/load_data_func.py
      - def load_data(): ... only (no imports)
      - Use **onp** from COMMON_UTILITIES (host numpy)
      - Load only vars that exist; keys like data_{var}, mc_{var}, truth_{var}
      - n_repeat = 1 by default
      - n_truth_mc = 150000 by default  # cap truth-MC size for cost/memory
        (name the constant; optional one-line comment that it is NOT n_data)
      - 1D sbc: onp.tile(onp.load(...), n_repeat)
      - multi-dim amp: onp.tile(onp.load(...), (1, n_repeat, 1)) when rank-3
      - truth_* = mc_* sliced on the **event axis** to length n_truth_mc * n_repeat
        (1D: mc[0:n_truth_mc*n_repeat]; rank-3: mc[:, 0:n_truth_mc*n_repeat, ...])
      - Prefer a named constant over a bare magic number, e.g.:
          n_truth_mc = 150000
          data['truth_phi_kk'] = data['mc_phi_kk'][0:n_truth_mc * n_repeat]
      - return data dict

   b) gen/fragments/normalize_data_func.py
      - def normalize_data(data): ... only (no imports)
      - Use **onp** for host-side averages / einsum
      - For each multi-component amp var present (typically *phif* with rank 3):
        regular = 1 / mean(sqrt(sum(mc_arr**2, axis=last_component)), axis=event)
        scale data/mc/truth with onp.einsum along the channel axis
      - Leave pure 1D sbc vars unchanged
      - return data

   c) gen/fragments/shard_data_distributed_func.py
      - def shard_data_distributed(data, mesh): ... only (no imports)
      - Use **np** (jax.numpy), **device_put**, **NamedSharding**, **P** from
        COMMON_UTILITIES — do not import jax / jnp yourself
      - Shard event-1d keys with NamedSharding(mesh, P("event"))
      - Shard rank-3 keys with NamedSharding(mesh, P(None, "event", None))
      - return jax_data dict of device_put arrays

5. Optional: syntax-check each .py with
   python -c "import ast; ast.parse(open(path).read()); print('OK', path)"

6. Finish (result is a **short summary only**, not a second copy of the report):
   task(
     action="finish",
     result=<1-5 lines: n_data, n_truth_mc, file counts, paths written; no full report body>,
     outputs={
       "all": "gen/fragments/data_shapes_report.txt",
       "load_data": "gen/fragments/load_data_func.py",
       "normalize_data": "gen/fragments/normalize_data_func.py",
       "shard_data_distributed": "gen/fragments/shard_data_distributed_func.py"
     }
   )

## How stage outputs are recorded (important)
