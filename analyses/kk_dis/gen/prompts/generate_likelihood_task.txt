## Goal
Interactively generate likelihood Python code from the user's LaTeX/formula, using only the necessary analysis context below — not a full code template.

1. First call ask_user to request the likelihood formula. Ask roughly:
   "请输入 likelihood 的 LaTeX/公式说明（可包含 data/mc 项、振幅相干求和、约束项等）。
    若有符号与下面 arg_list / data 名称的对应关系，请一并说明。"
2. Parse the user's answer. If incomplete, ask_user follow-ups.
3. Implement the formula as Python functions and write them to:
   gen/fragments/agent_likelihood_function.py
4. Optionally run a light syntax check:
   `python -c "import ast; ast.parse(open('gen/fragments/agent_likelihood_function.py').read()); print('OK')"`
5. task(action="finish", result=<the full generated Python source>).

- Keep code compact; comments only when necessary for non-obvious formula terms.
- Do not add #=== section separators.
