Hard rules:
1. Write the deliverable to **run/fit_script.py**.
2. Reuse **run/base_functions.py** and **run/likelihood_function.py** — do not re-implement
   dplex_*, BW/flatte*, load_data / normalize_data / shard_data_distributed,

   optimizer + broadcast request/response loop** architecture:

   count varies between processes, so an all-ranks minimize desynchronizes the
   collective order and deadlocks. The request/response loop keeps both sides'
   collectives strictly one-to-one (chief dispatches before every JAX eval).
5. Adapt call signatures to THIS analysis's actual APIs (read the two modules first).
6. Stay inside the analysis workspace; do not search or depend on external example scripts.
7. No markdown fences in the saved .py.
8. Prefer compact code; no long #==== banner comments.
9. After writing, run a light syntax/import smoke (not a full minimize) if feasible,
   then task.finish.
