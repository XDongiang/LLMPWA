## 6. 叙述：做了什么、还有什么问题（手工）

### 这条链是什么

例 2 `ψ→K⁺K⁻π⁰` 的 **KK̄ 共振家族**（`ρ'`，文档 274–304 行的 `U_{ρ'}^μ`）。

例 2 与例 1 容易看混，但结构差别很大：

| | 例 1 `π⁺π⁻π⁰` | 例 2 `K⁺K⁻π⁰` |
|---|---|---|
| 三体末态 | 是 | 是 |
| 置换族 | 一个族，三项 `{12,13,23}` 全排列 | **两个族**：KK̄ 共振 + Kπ 共振 |
| 本链 | — | KK̄ 共振，**只有一项** |

### 为什么只有一条道

文档：

$$
U_{\rho'}^\mu = \epsilon_{\mu\nu\lambda\sigma} p_1^\nu p_2^\lambda p_3^\sigma
  B_1(Q_{\psi\rho' 3}) f^{(\rho')}_{(12)} B_1(Q_{\rho' 12})
$$

**单项**，没有 `(1↔3)`/`(2↔3)`。原因很实在：`(12)` 是 K⁺K⁻ 对，把 1 或 2
换成 π⁰ 就变成 Kπ 系统，那是 **K\*** 不是 ρ′。所以 ρ′ 只能配 (12) 这一对。

Kπ 子系统的那两项在 [`ex2_kstar`](ex2_kstar.md)。

### 判据与实测

| 判据 | 结果 |
|---|---|
| `ε·B` 恒等式（J=1，适用） | 残差 6.7e-16，\|c\| = 0.191835806 |
| 置换协变性 | **跳过**：只有一条道，没有置换伙伴 |
| `check` | ✅ |
| `emit`（cascade） | ✅ |

单独一条道没什么可"置换"的，所以本链的验收价值主要在于
**它和 K\* 族加起来才构成完整的例 2** —— 这一点由
`test_ex12_permutation.py` 的 case 表覆盖（两族各自都验）。

### 质量参数的注意点

`rho` 的质量写 1.9（占位）。它只影响 `q^2` 的数值，不影响文档公式 ——
协变张量道对任意四动量都成立。但**不能**取得太低：低于 `2 m_K` 会让
`q^2 < 0`、`B_1` 出 NaN。`data/make_threebody.py` 里 `resonance_mass`
取同值，两者要一致。
