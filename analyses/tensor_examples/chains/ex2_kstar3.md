## 6. 叙述：做了什么、还有什么问题（手工）

### 这条链是什么

例 2 `ψ→K⁺K⁻π⁰` 的 **K\*₃(3⁻) 家族**（文档 274–304 行的 `U_{K^*_3}^μ`）。

与 [`ex2_kstar`](ex2_kstar.md)（J=1）和 [`ex2_kstar5`](ex2_kstar5.md)（J=5）
同构：只有 `(13)`/`(23)` 两对（K⁺K⁻ 是同种粒子，1↔2 不产生新配对），
只是 J=1 → 3、l=1 → 3。

它和 [`ex1_rho3`](ex1_rho3.md) 是同一类：**J≥3 只验置换协变性**，
不验 `ε·B` 恒等式 —— 那个化简只对 J=1 成立（见下）。

### ⚠️ 文档的 `- (1↔2)` 不是道间相对符号

文档写：

$$
U_{K^*_3}^\mu = \epsilon_{\mu\nu\lambda\sigma}p_\psi^\sigma
  [\tilde T^{(3)\cdots}_{(K^*_3 2)}\tilde t^{(3)\cdots}_{(13)}
    f^{(K^*_3)}_{(13)} - (1\leftrightarrow 2)]
$$

实测两条道**同号**：

```
A_13(交换 0<->1 的动量) / A_23(原动量) = +1.000000   残差 0.00e+00
```

这与 J=1 的 `U_{K*}`、J=5 的 `U_{K*_5}` **完全一致** —— Kπ 家族的
`-(1↔2)` 那个负号始终来自 `T̃^{(J)}` 张量缩并的**整体**因子，
不是道与道之间的相对符号。所以本链两条道直接相加。

⚠️ 别和**例 1 的 ρ₃/ρ₅** 混淆：那里 `(1↔3)`/`(2↔3)` 后两项**确实**
要反号（实测 `c = -1.000000`）。差别来自置换的奇偶性与配对结构，
**只能实测，不能照抄文档符号**。

### J≥3 的 `ε·B` 恒等式为什么不成立

J=1 时 `T̃^{(1)}_ν` 是矢量，`ε·p_ψ·T̃·t̃` 三个矢量缩并正好退化成一个
`ε_{μνλσ}p₁p₂p₃`。J=3 时 `T̃^{(3)ν}_{αβ}` 带两个额外指标，缩并结果是
**秩 2** 的对象，化不成单个 ε 张量。实测残差 1.04（结构性，不是噪声）。

所以本链的验收判据只有置换协变性。

### 判据与实测

| 判据 | 结果 |
|---|---|
| 置换协变性（`_13` 交换 0↔1 的动量 vs `_23`） | 残差 0，`c = +1.000000`（同号） |
| 振幅有限 | ✅ `|A|max = 118.2` |
| `ε·B` 恒等式 | 不适用（J=3 结构上不成立） |
| `check` / `emit`（cascade） | ✅ |

⚠️ 与其它三体 spec 一样，**只有 `helicity_cascade` 能 emit**：
`cartesian`/`helicity` 要把 `agent/tensor/chains/<chain>/<channel>.py` 里的
**手写**道函数内联，而三体置换道没有手写函数（会报 `LookupError`）。
J=3 本身在协变张量路线的 4 以内，但"有张量公式"≠"能 emit" —— 这是两件事。

### 与 K\*₅ 的关系

两条链合起来覆盖了 Kπ 子系统的 J=1 / 3 / 5 三个共振：
[`ex2_kstar`](ex2_kstar.md)（1⁻）、本条（3⁻）、[`ex2_kstar5`](ex2_kstar5.md)（5⁻）。
J=3 用不上 2026-10-20 那次上限扩展（3 ≤ 4），J=5 才需要。
