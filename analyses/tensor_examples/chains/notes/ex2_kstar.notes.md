### 这条链是什么

例 2 `ψ→K⁺K⁻π⁰` 的 **Kπ 共振家族**（`K*`，文档 274–304 行的 `U_{K^*}^μ`）。

这是例 2 里真正有"置换求和"的那一半。

### 为什么是两条道（而不是三条）

文档：

$$
U_{K^*}^\mu = \epsilon_{\mu\nu\lambda\sigma} p_1^\nu p_2^\lambda p_3^\sigma
  \Bigl[B_1(Q_{\psi K^* 2}) f^{(K^*)}_{(13)} B_1(Q_{K^* 13})
      + B_1(Q_{\psi K^* 1}) f^{(K^*)}_{(23)} B_1(Q_{K^* 23})\Bigr]
$$

只有 `(13)` 和 `(23)` 两项，**没有 (12)**。而且这两项是**相加**（同号）。

两个原因：

1. `(12)` 是 K⁺K⁻，不是 Kπ，配不出 K\*；
2. K⁺ 与 K⁻ 是**同种粒子**（都是 K），交换 1↔2 不产生新的物理配对 ——
   所以只有 2 项，不像例 1 的 π 三项全排列。

实测两项确实同号：`A_13(交换 0↔1 的动量)` 与 `A_23` 的比值是 `+1.000000`
（残差 1.8e-16）。

⚠️ 别和文档的 `U_{K^*_3}` 搞混：那里写的是 `f^{(K^*_3)}_{(13)} - (1↔2)`，
**带负号**。那是 J=3 的 `T̃⁽³⁾` 缩并，与 J=1 的 `U_{K^*}` 不是一回事。
J=3 版本未实现（见下）。

### 判据与实测

| 判据 | 结果 |
|---|---|
| 置换协变性（`_13` 交换 0↔1 的动量 vs `_23`） | 残差 1.8e-16，`c = +1.000000`（文档要的同号） |
| `ε·B` 恒等式 | 残差 ≤ 2.9e-15，\|c\| = 0.191835806 两道一致 |
| `check` | ✅ |
| `emit`（cascade） | ✅ |

### 未实现的部分

文档还有 `U_{K^*_3}` 与 `U_{K^*_5}`：

* `K*₃`（J=3）：技术上可以加（`LAM_SLOTS` 到 4），沿 `ex1_rho3` 的路子做。
  未加是因为例 2 的验收价值主要在"两族相加"，J=3 版本属边际增益。
* `K*₅`（J=5）：**超出内核上限**（J=5 与 l=5 都越界），要扩
  `small_d_weight` / `cg` / `Bl`，属新基建。

### 质量参数的注意点

`kstar` 质量写 0.892（真实 K\* 质量）。`data/make_threebody.py` 的
`resonance_mass` 取 1.9 —— **两者不必一致**：spec 里的质量只影响该节点
`q^2` 的数值，相空间用哪个中间态质量只影响事例分布。
