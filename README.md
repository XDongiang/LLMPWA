# LLMPWA — LLM-Powered Partial Wave Analysis Code Generator

LLMPWA drives an LLM/Agent pipeline to turn a declarative resonance configuration into
partial wave analysis (PWA) fitting code. The end-to-end reference is
[`analyses/kk_dis`](analyses/kk_dis/README.md): it starts from `resonances_config.toml`
and produces a distributed JAX + SciPy Newton-CG fit entry point.

## How it works

1. Declare resonances and amplitudes in a TOML config (`resonances_config.toml`).
2. The `agent/` engine executes a staged `llm_config_*.toml` pipeline
   (`kind = python | llm | agent`). Each stage's outputs are registered into a manifest so
   downstream stages can reference them with `<<stages.xxx.yyy>>`.
3. Reusable numeric/template primitives come from templates; analysis-specific glue
   (data shapes, likelihood formula, fit entry point) is generated by the LLM/Agent.
4. The result is a runnable `run/fit_script.py`, launchable on a multinode Docker cluster.

## Requirements

- Python 3.8+ (3.11+ recommended, so the stdlib `tomllib` is used where available)
- An EasyTrans LLM API key (`EASYTRANS_API_KEY`)

### Install the generator dependencies

```bash
pip install -r requirements.txt
```

This installs `openai`, `python-dotenv`, and `toml` — the only packages the generator
itself needs. To **run** the generated fitting code, install the `runtime` extra in
`pyproject.toml` (JAX, NumPy, SciPy, ...) and set up your CUDA/JAX environment.

### Configure API access

```bash
export EASYTRANS_API_KEY="your_api_key_here"
# optional overrides
export EASYTRANS_BASE_URL="https://api.easytransnote.com/v1"
export EASYTRANS_MODEL="gemini-2.5-pro"
```

## Usage

### Generate code for an analysis

```bash
# static checks only
python -m agent.cli --workdir analyses/kk_dis --config llm_config_fit.toml --check-only

# run the full pipeline
python -m agent.cli --workdir analyses/kk_dis --config llm_config_fit.toml

# re-run a single stage
python -m agent.cli --workdir analyses/kk_dis --config llm_config_fit.toml --stage generate_fit_script
```

See [`analyses/kk_dis/README.md`](analyses/kk_dis/README.md) for the full stage list and
runtime contracts.

### Run the generated fit (single node)

```bash
cd analyses/kk_dis
python run/fit_script.py
```

### Run the generated fit (multinode Docker)

```bash
./docker/run_fit_multinode.sh --workdir analyses/kk_dis
```

